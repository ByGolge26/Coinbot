YATIRIM BOTU V18 KURULUM

1) GitHub
- V16 dosyalarının yerine bu ZIP içindeki dosyaları koy.
- Commit changes yap.

2) Render Environment
- GROQ_API_KEY: mevcut Groq API anahtarın
- AI_MODEL: openai/gpt-oss-20b
- AI_FALLBACK_MODEL: openai/gpt-oss-20b
- AI_CANDIDATES: 8
- AI_MIN_SCORE: 70
- SCAN_LIMIT: 40
- SCAN_INTERVAL_SECONDS: 600
- MIN_BUY_TRY: 1000
- MIN_LOSS_TRY: 100
- MIN_PROFIT_TRY: 150
- POSITION_SIZE_PCT: 0.25
- ACTIVE_CAPITAL_PCT: 0.75
- ALLOW_WITHOUT_AI: false
- DRY_RUN: true

3) Deploy
Render -> Manual Deploy -> Deploy latest commit.

4) Kontrol
Panelde Yatırım Botu V18 ve 'web araştırması kapalı' yazmalı. AI isteği tek toplu çağrıdır. 429 olursa otomatik cooldown uygulanır.

5) Güvenlik
DRY_RUN=true bırak. Gerçek para ile işlem açmadan önce sanal AL/SAT zincirini doğrula.
